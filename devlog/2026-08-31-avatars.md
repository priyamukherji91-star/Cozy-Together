tags: Developments, Done

**Summary**
Profile pictures can now be uploaded with a start and end date. The built-in occasions (Halloween, Christmas, Easter, Ramadan/Eid, Pride, summer) are unchanged and still run off the calendar.

**Location**
Administration → Mittens the Menace → Avatar

**Actions**
• Add an avatar — name + start/end date in a form, then post the image in the channel
• Remove an avatar — hand-added ones only
• Manually change avatar — pin one, or `auto` to follow the calendar again
• Sync the avatar — apply today's occasion now
• Avatar schedule — what's live, what's next, what's been added

**Notes**
• Overlap check on add: a clash with a built-in occasion or another upload is rejected, naming the conflict and its dates
• Windows are absolute dates, not yearly repeats
• Uploads are stored on the volume and survive deploys
• Also typeable: `/avatar_add`, `/avatar_remove`
• Discord modals can't take file uploads, hence the "post the image" step — same flow as pet photo swaps
